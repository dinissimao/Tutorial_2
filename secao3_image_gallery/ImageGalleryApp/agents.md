# AI Agent Guidelines

The AI agent must follow a planning-first approach.

## Rules
- Always read all documentation inside /docs before generating any code.
- Follow the architecture defined in docs/06_architecture.md.
- Generate Kotlin code only.
- UI must use XML Views (do NOT use Jetpack Compose).
- Do not generate large files at once — generate code step-by-step.
- Follow the implementation plan in docs/08_implementation_plan.md strictly.
- Always ask for review before proceeding to the next step.
- Do not skip steps in the implementation plan.
