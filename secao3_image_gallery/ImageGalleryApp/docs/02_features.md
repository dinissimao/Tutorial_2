# Funcionalidades

1. **Obter imagens da API** — obtém 20 imagens aleatórias de cães da Dog CEO API
2. **Apresentar imagens em grelha** — RecyclerView com grelha de 2 colunas
3. **Actualizar galeria** — botão de refresh para obter novas imagens
4. **Indicador de carregamento** — ProgressBar visível enquanto as imagens carregam
5. **Ecrã de detalhes** — ao carregar numa imagem, abre um ecrã com mais informação
6. **Sistema de favoritos** — guardar até 5 imagens favoritas (fila FIFO)
7. **Acesso aos favoritos** — barra de favoritos acessível a partir de qualquer ecrã
8. **Cache de imagens** — cache de até 50 imagens para acesso offline
9. **Acesso offline** — visualizar imagens em cache sem ligação à internet
10. **Tratamento de erros** — mensagens de erro amigáveis quando a API falha
