# Ecrãs da Aplicação

## Ecrã Principal (MainActivity)
Componentes:
- Toolbar com título "Image Gallery"
- RecyclerView em grelha de 2 colunas com imagens
- Botão de refresh para actualizar as imagens
- ProgressBar centralizado (visível durante o carregamento)
- Barra horizontal de favoritos na parte inferior (5 slots)
- Mensagem de erro (visível apenas quando a API falha)

## Ecrã de Detalhes (ImageDetailsActivity)
Componentes:
- Toolbar com botão de voltar
- Imagem em tamanho grande
- Informação da imagem (URL, índice)
- Botão para adicionar/remover dos favoritos
