# ImageGalleryApp

## Descrição
Aplicação Android que obtém e apresenta imagens de cães de raças aleatórias através da Dog CEO API. O utilizador pode actualizar a galeria, ver detalhes de cada imagem e guardar as suas favoritas.

## API utilizada
- **Dog CEO API**: https://dog.ceo/dog-api
- Endpoint principal: `https://dog.ceo/api/breeds/image/random/20`

## Funcionalidades
- Galeria de imagens em grelha
- Botão de actualização
- Ecrã de detalhes de cada imagem
- Sistema de favoritos (máximo 5, fila FIFO)
- Cache de até 50 imagens
- Indicador de carregamento
- Acesso offline às imagens em cache

## Como correr o projeto
1. Abre o projeto no Android Studio
2. Aguarda o Gradle sincronizar
3. Corre a app num emulador ou dispositivo físico com Android 7.0+
